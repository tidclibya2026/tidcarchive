# التحقق من تنزيل PDF المحمي للوثائق الرسمية

**التاريخ:** 20 أغسطس 2026  
**النطاق:** القرارات الإدارية والمناشير الداخلية في نظام TIDC.

## النتيجة

أصبح زر **«تنزيل PDF»** في سجلي القرارات والمناشير يقود إلى مسار محمي على الخادم، ولا يكشف عنوان التخزين أو مفتاح الملف إلى الواجهة. المسار يقرأ جلسة المستخدم مع كل طلب، ثم يتحقق من الدور الإداري ونطاق الإدارة أو المكتب قبل إصدار تنزيل قصير المدة في بيئة التخزين المدارة، أو قبل فك تشفير وإرسال الملف في بيئة MinIO المحلية.

| طبقة الحماية | السلوك المتحقق |
|---|---|
| رابط الواجهة | يستخدم `/api/official-documents/{type}/{id}/download` بدلاً من `/manus-storage/...`. |
| الجلسة | الطلب غير المسجل يُرفض بحالة HTTP `401`. |
| التفويض | الحسابات التنفيذية أو ذات الصلاحية الشاملة مسموح لها، والحساب المقيد يُقبل فقط داخل نطاق الإدارة أو المكتب المصدِر. |
| التخزين المباشر | مسارات `tidc-archive/decision/` و`tidc-archive/circular/` لا تُخدَّم من بوابة التخزين العامة، وتُرجع `404`. |
| التخزين المحلي | الملف المفكوك بتشفير AES-256-GCM لا يُرسل إلا بعد تحقق الجلسة والتفويض. |
| التخزين المدار | يُنشأ تحويل `307` إلى رابط تنزيل موقّع قصير المدة فقط بعد التفويض. |

## أدلة التحقق الآلي والتشغيلي

أُجريت اختبارات وحدة لمسار التنزيل نفسه تشمل الرفض قبل الوصول إلى التخزين عند غياب الجلسة، ورفض حساب خارج نطاق الوثيقة، وقبول الحساب داخل النطاق مع إنشاء تنزيل موقّع. كما تحقق اختبار الواجهة أن الزر لا يحتوي على رابط `/manus-storage/`.

| الفحص | النتيجة |
|---|---|
| اختبارات المشروع الكاملة | **45 ناجحة**، و**1 متخطى**. |
| فحص TypeScript | ناجح بلا أخطاء. |
| بناء الإنتاج | ناجح. |
| طلب تنزيل قرار بلا جلسة | `401 Unauthorized`. |
| طلب تخزين مباشر لمسار قرار رسمي | `404 Not Found`. |

## التحقق اليدوي المتبقي

لا توجد في قاعدة بيانات التطوير الحالية قرارات أو مناشير مرتبطة بملف PDF حقيقي؛ لذلك لم يُنشأ قرار تجريبي في السجل الرسمي لمجرد الاختبار. عند تسجيل أول قرار تدريبي مع ملف PDF معتمد، ينفذ مسؤول النظام التحقق اليدوي الآتي:

1. يسجّل الدخول بحساب مخول من نفس نطاق الإدارة أو بحساب تنفيذي.
2. يفتح **القرارات الإدارية** أو **المناشير الداخلية** ثم يختار **تنزيل PDF**.
3. يتحقق من تنزيل الملف باسمه العربي وفتحه بصورة سليمة.
4. يعيد الطلب بحساب خارج نطاق الجهة المصدرة؛ يجب ألا يصل إلى الملف.
5. يسجل النتيجة وتاريخ الاختبار واسم المختبر في سجل الاستلام المحلي دون إدراج كلمات مرور أو محتوى الوثيقة.

> لا يُنصح باختبار التنزيل بإنشاء قرار صوري في قاعدة تشغيل الموظفين، لأن سجل القرارات وثيقة إدارية رسمية.
