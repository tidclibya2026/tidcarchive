# إدارة الحسابات المحلية والصلاحيات — TIDC

## نطاق الإدارة

يدعم النظام حسابات محلية بالبريد وكلمة المرور إلى جانب جلسات المنصة القائمة، حتى يمكن تشغيله لاحقًا على الخادم المحلي للمركز. يرتبط كل حساب بدور مؤسسي وبإدارة، ويمكن أن يرتبط كذلك بمكتب محدد في الهيكل التنظيمي. لا يُخزّن النظام كلمة المرور بصيغتها الصريحة؛ بل يخزّن بصمة مشتقة من كلمة المرور باستخدام ملح عشوائي ودالة اشتقاق مقاومة للهجمات التخمنية.

| الدور | نطاق الوصول الافتراضي |
|---|---|
| مدير النظام | إدارة الحسابات والبنية التنظيمية وجميع وثائق النظام. |
| المدير العام | الاطلاع الإداري الشامل والقرارات والتقارير. |
| مكتب المتابعة | متابعة المعاملات والإحالات والتقارير التشغيلية. |
| رئيس إدارة | إدارة معاملات الإدارة والمكاتب التابعة لها. |
| موظف | المعاملات المسندة إلى إدارته أو مكتبه فقط. |

## دورة الحساب

ينشئ مدير النظام الحساب، ويحدد الاسم والبريد والدور والإدارة والمكتب وكلمة مرور أولية. يكون لكل حساب حالة نشط أو موقوف. لا تسمح إجراءات الخادم بتسجيل الدخول لحساب موقوف، ولا ترسل حقل بصمة كلمة المرور إلى المتصفح أو إلى أي استجابة API. تسجل عمليات الإنشاء والتفعيل والتعطيل وتغيير الدور وإعادة تعيين كلمة المرور في سجل نشاط الحسابات.

## الحساب الإداري الأولي

يُنشأ الحساب الإداري الأولي مرة واحدة من أمر تشغيل داخلي بعد تطبيق ترحيل قاعدة البيانات. يأخذ الأمر البريد وكلمة المرور من متغيرات تشغيل مؤقتة ولا يكتب القيمة الصريحة إلى ملفات المشروع أو قاعدة البيانات. بعد إنشاء الحساب، يجب تغيير كلمة المرور الأولية داخل بيئة التشغيل الفعلية وحفظها في مدير كلمات مرور مؤسسي.
