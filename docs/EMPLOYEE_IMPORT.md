# إدخال الموظفين الفعليين — TIDC

يُستخدم الملف `templates/employee_import_template.csv` عند اعتماد قائمة الموظفين. يحتوي القالب على رأس الأعمدة فقط ولا ينشئ حسابات أو موظفين تمثيليين.

| العمود | المتطلب |
|---|---|
| الاسم الكامل | الاسم المعتمد في الهيكل أو ملفات الموارد البشرية. |
| البريد المؤسسي | بريد فريد لكل موظف؛ لا يقبل التكرار. |
| الدور | أحد القيم: `admin`، `director_general`، `follow_up`، `department_head`، `staff`. |
| الإدارة | اسم إدارة مطابق للهيكل المستورد، أو يترك فارغًا عند التبعية لمكتب فقط. |
| المكتب | اسم مكتب مطابق للهيكل المستورد، أو يترك فارغًا عند التبعية لإدارة فقط. |
| الحالة | `yes` لحساب نشط أو `no` لحساب موقوف. |

تتحقق عملية الاستيراد قبل الكتابة من البريد والدور ووجود الإدارة أو المكتب وعدم التكرار. تُنشأ كلمات المرور الأولية كروابط أو إجراءات إعادة تعيين منفصلة، ولا يُقبل تخزينها كنص عادي داخل ملف الاستيراد.
