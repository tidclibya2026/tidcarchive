نظام الأرشفة الإلكترونية والمتابعة

مركز المعلومات والتوثيق السياحي (TIDC) — مراسلات، قرارات، مناشير، متابعة، أرشيف رقمي، وتقارير.

هذا المستودع يحفظ مصدر النظام فقط. تشغيل الأرشفة الفعلية يتطلب خادم التطبيق وقاعدة البيانات وتخزين المرفقات والمصادقة وOCR؛ وهي متاحة في نسخة النظام الخادمة وليس في GitHub Pages.

محتوى النظام

يشمل المستودع واجهة النظام والخادم ومخطط قاعدة البيانات وترحيلات البيانات وحزمة تشغيل الخادم المحلي والأدلة الفنية.

التجربة الفعلية

تسجيل المراسلات ورفع المستندات والبحث الفعلي والصلاحيات يتم عبر رابط النظام الخادم فقط، لا عبر صفحة GitHub الثابتة.

حماية البيانات

لا يحتوي المستودع على كلمات مرور أو مفاتيح تشفير أو ملفات بيئة أو مرفقات معاملات حقيقية.

فتح مستودع الكود
التشغيل المؤسسي النهائي يتم على خادم المركز وفق إجراءات الاستلام الفني والحماية المعتمدة.
