نظام الأرشفة الإلكترونية والمتابعة

مركز المعلومات والتوثيق السياحي (TIDC) — إدارة الوارد والصادر والقرارات والمناشير والإحالات والأرشيف الرقمي والتقارير.

صفحة مرجعية للمستودع فقط. المنظومة الكاملة تحتاج خادم تطبيق وقاعدة بيانات وتخزين مرفقات وOCR، لذلك لا تعمل من GitHub Pages. حُدِّث المصدر ليشمل البحث المتقدم في الأرشيف وتحسينات لوحة القيادة ضمن بيئة التطبيق الكاملة.

المراسلات ودورة العمل

تسجيل الوارد والصادر، الإحالات، الأولويات، المواعيد، وسجل النشاط والمتابعة.

الأرشيف والبحث المتقدم

بحث عربي بالنوع والحالة والأولوية والإدارة والفترة الزمنية، مع فهرسة نصوص OCR للمرفقات المدعومة.

المستخدمون والتقارير

صلاحيات مؤسسية، إدارة مستخدمين، سجل تدقيق، لوحات مؤشرات وتقارير إدارية عربية متجاوبة.
