نظام الأرشفة الإلكترونية والمتابعة

مركز المعلومات والتوثيق السياحي (TIDC) — إدارة المراسلات والقرارات والمناشير والإحالات والأرشيف الرقمي والتقارير.

هذه صفحة تعريفية للمستودع فقط. نظام TIDC الكامل يتطلب خادماً وقاعدة بيانات وتخزين مرفقات وOCR، لذلك لا يعمل من GitHub Pages. يستخدم المستودع لحفظ الكود والوثائق وحزمة التشغيل المعتمدة.

المراسلات ودورة العمل

تسجيل الوارد والصادر، الإحالات، الأولويات، المواعيد، وسجل النشاط والمتابعة.

الأرشيف والمرفقات

رفع PDF والصور، التصوير من الهاتف، فحص الملفات، OCR عربي، والبحث في النص المستخرج.

المستخدمون والتقارير

صلاحيات مؤسسية، إدارة المستخدمين، سجل تدقيق، ولوحات وتقارير إدارية عربية.

استخدام المستودع

يحفظ المستودع مصدر الواجهة والخادم ومخطط قاعدة البيانات وحزمة تشغيل الخادم المحلي والأدلة الفنية. لا يحفظ كلمات المرور أو ملف .env أو مفاتيح التشفير أو مرفقات المعاملات الحقيقية.

  • التدريب العملي يحتاج بيئة تطبيق كاملة ببيانات تدريب منفصلة.
  • التشغيل النهائي يتم على خادم المركز باسم tidc.ly بعد الاستلام الفني.
  • لا تفتح قاعدة البيانات أو MinIO أو OCR مباشرة إلى شبكة المستخدمين.
