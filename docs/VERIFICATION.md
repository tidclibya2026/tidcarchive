# سجل التحقق — النسخة التجريبية

تم التحقق من لوحة القيادة العربية RTL على سطح المكتب والهاتف، ومن استجابة صفحة المراسلات في عرض الهاتف. أُعيد ضبط جدول المراسلات ليخفي الأعمدة الثانوية على الشاشات الصغيرة مع إبقاء الرقم والموضوع والحالة والإجراء ظاهرين.

تمت معاينة مسار نموذج التسجيل المحمول والتحقق من وجود اختيار ملف، زر تصوير يستخدم كاميرا الجهاز الخلفية عند الدعم، معاينة مصغرة للصور قبل الحفظ، وحالة رفع منفصلة لكل مرفق. كما أُعيد ضبط عرض نافذة التسجيل لتستخدم عرض الشاشة المتاح في الهاتف.

تُراجع صفحة مكتب المتابعة في الفحص النهائي بعد استقرار استعلامات المصادقة والبيانات، مع تشغيل اختبارات Vitest والتحقق من الأنواع والبناء قبل حفظ الإصدار.

## توسعة الهوية والتقارير

تمت إضافة الشعار الرسمي وهوية دولة ليبيا ووزارة السياحة والصناعات التقليدية إلى الواجهة. كما أُضيفت صفحة تقارير رسومية تستند إلى تجميعات حية للوارد والصادر والقرارات والمناشير، وتوزيع المراسلات حسب الإدارة والمكتب والجهة. أظهر الالتقاط الأولي للحالتين الهيكل الانتظاري للمصادقة؛ لذلك سيُعاد الفحص بعد استقرار الاستعلامات قبل التسليم.

أُعيد التقاط صفحة التقارير وصفحة القرارات بعد استقرار الاستعلامات. ظهر الشعار والهوية المؤسسية وقيم الرسومات الحية وحالات البيانات الفارغة بوضوح، كما ظهرت رسالة أرشفة PDF الإلزامية في سجل القرارات. لا توجد بيانات تشغيلية مسجلة حاليًا؛ لذلك تعرض الرسومات والأرقام الصفرية الحالة الحقيقية لقاعدة البيانات بدل استخدام بيانات تجريبية.

أعيدت محاولة فحص الهاتف لمساري التقارير ونموذج القرار عبر رابط مباشر، إلا أن الالتقاط المتزامن أظهر هيكل انتظار المصادقة قبل اكتمال تحميل الجلسة. تم تأكيد نجاح البناء والأنواع واختبارات الوحدة، ويُعاد فحص الواجهة بعد استقرار جلسة المعاينة قبل نقطة الحفظ.

اكتمل فحص الهاتف اللاحق لنموذج القرار بعد استقرار الجلسة: ظهر العنوان المؤسسي، وحقول القرار، ومنطقة **أرشفة PDF إلزامية** وزر اختيار PDF والتنبيه الذي يمنع اعتماد التسجيل دون ملف. يؤكد ذلك استجابة نموذج الأرشفة الرسمي على شاشة الهاتف.

اكتمل فحص الهاتف لصفحة التقارير بعد استقرار الجلسة أيضًا. ظهر العنوان المؤسسي الليبي، ووصف التقارير، وشرائح إجمالي الوثائق والوارد والصادر والقرارات والمناشير بتنسيق RTL متجاوب. لا تزال القيم صفرية لعدم وجود سجلات تشغيلية فعلية في قاعدة البيانات الحالية.
