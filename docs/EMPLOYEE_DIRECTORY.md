# دليل الموظفين المستورد — TIDC

أُدخلت القائمة المرسلة كسجلات تنظيمية غير مفعلة فقط. لم يُنشأ بريد إلكتروني أو كلمة مرور افتراضية لأي موظف، ولذلك لا يستطيع أي سجل جديد تسجيل الدخول قبل اعتماد بريد مؤسسي فريد وإتمام التفعيل من مدير النظام.

| الموظف | الدور في النظام | التعيين التنظيمي | حالة الدخول |
|---|---|---|---|
| أسامة فرج الخبولي | المدير العام | مكتب المدير العام | معلق بانتظار البريد |
| ابتهاج الهواري | رئيس وحدة | مكتب المدير العام | معلق بانتظار البريد |
| أحمد عيسي | موظف | مكتب المتابعة | معلق بانتظار البريد |
| أنس القائدي | رئيس وحدة | مكتب التصرف تحت الخدمة | معلق بانتظار البريد |
| روفيد البوزيدي | مكتب المتابعة | مكتب المتابعة | معلق بانتظار البريد |
| عبدالرحمن بن سعيد مكير | موظف | مكتب الشؤون القانونية | معلق بانتظار البريد |
| عبدالقادر | رئيس وحدة | مكتب شؤون الفروع | معلق بانتظار البريد |
| عبدالرحمن عيسي | رئيس إدارة | إدارة الشؤون الإدارية والمالية | معلق بانتظار البريد |
| حسن زهيدة | رئيس إدارة | إدارة الدراسات والتخطيط | معلق بانتظار البريد |
| ايمن زرتي | رئيس إدارة | إدارة التوثيق والأرشفة | معلق بانتظار البريد |
| عبدالحميد الزروق | رئيس إدارة | إدارة تكنولوجيا المعلومات | معلق بانتظار البريد |
| زينة عبدالقادر | رئيس قسم | قسم الشؤون الإدارية | معلق بانتظار البريد |

أضيف إلى الهيكل كذلك **مكتب التصرف تحت الخدمة** و**قسم الشؤون الإدارية** حتى تتطابق التعيينات مع القائمة الواردة. عند استلام البريد المؤسسي لكل موظف، تُحدّث السجلات القائمة نفسها ثم تُفعّل الحسابات بكلمات مرور أو روابط تفعيل منفصلة وآمنة.
